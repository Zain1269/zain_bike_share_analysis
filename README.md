# Zain Bike Share Analysis

An end-to-end data analysis project using SQL and Power BI to explore bike-sharing usage patterns, rider behavior, and key performance indicators.

## Project Overview

This project analyzes bike-sharing data to understand how customers use the bike-sharing service and identify patterns in usage across different times, conditions, and rider types.

The analysis combines SQL for data preparation and exploration with Power BI for interactive visualization and dashboard development.

## Objective

The goal of this project was to analyze bike-sharing data and transform the raw dataset into meaningful insights through SQL analysis and an interactive Power BI dashboard.

The project focuses on understanding usage patterns, rider behavior, and key business metrics.

## Analysis Areas

* Bike-sharing usage patterns
* Rider behavior
* Registered vs. casual riders
* Seasonal trends
* Hourly usage patterns
* Weekday and working-day patterns
* Weather conditions
* Rider activity and performance indicators

## Tools & Technologies

* SQL
* Power BI
* Power Query
* DAX
* Data Modeling
* Data Visualization

## Analysis Process

### 1. Data Preparation

Prepared and structured the bike-sharing dataset for analysis.

The dataset covered multiple dimensions of bike usage, including date, time, season, weather, working day, rider type, and number of riders.

### 2. SQL Analysis

Used SQL to clean, transform, and analyze the dataset.

The analysis included filtering, aggregations, grouping, and Common Table Expressions (CTEs) to prepare the data and answer analytical questions.

### 3. Data Modeling

Prepared the data model required for analyzing bike-sharing activity and connecting the relevant data fields.

### 4. Power BI Dashboard

Built an interactive Power BI dashboard to visualize the results of the analysis.

The dashboard presents key performance indicators and visualizations that make it easier to explore rider behavior and usage patterns.

### 5. Insights

Analyzed the results to identify meaningful patterns in bike-sharing usage and compare rider behavior across different dimensions.
